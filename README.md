# 小红书收藏夹整理助手

自动整理小红书收藏夹——检测没有分类、放错专辑的笔记，按你的文件夹结构分类并批量归位。

## 为什么需要它

小红书的收藏夹是一个只进不出的仓库：几千条笔记、几十个专辑，越存越乱。

- 官方 App 只能一条一条操作，没有批量移动
- 网页端也没有「批量整理」功能
- 手动整理几千条收藏，基本等于一个不可能完成的任务

典型情况：**大量收藏没有任何专辑归属**（收藏越久，无归属比例越高）。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 检测 | 找出「无专辑」和「放错专辑」的笔记 |
| 分类 | 四层判定：专名专辑 → 工具实体 → 主体动作 → 场景兜底 |
| 确认 | 生成分类清单表格，你确认后再执行 |
| 执行 | 浏览器 UI 模拟点击，自动「加入专辑」 |
| 复查 | 逐专辑核对计数，汇报漏报/失败 |

## 核心设计：你的文件夹就是分类标准

不是给所有人一套死词典，而是从你**现有的专辑列表**反推规则：

- 你建了「五月天」专辑 → 所有五月天内容（阿信/鸟巢/wmls/卜卜）自动归它，而不是「音乐」
- 你建了「体育赛事」→ 樊振东/奥运内容归它
- 你删了「摄影与影像」→ 修图教程按现有体系归到「AI工具与效率」
- 外国地名（罗瓦涅米/赫尔辛基）→ 旅行
- 生活类（周末/探店/日常）→ 生活打卡与探店

## 工作流

① 盘点现状（抓收藏 + 专辑内容）
      ↓
② 生成分类清单（表格：标题 | 当前所在 | 建议归入 | 依据）
      ↓
③ 用户确认 / 修正（首批先审）
      ↓
④ 执行移动（UI 模拟点击）
      ↓
⑤ 复查（逐专辑计数核对 + 漏报汇报）

## 技术原理

不逆向签名、不登录代理，全部在**你自己已登录的浏览器**里完成：

1. **读取**：滚动抓取收藏列表（等同正常浏览）+ 专辑内容游标分页
2. **调用**：通过页面自带的 API 客户端发起请求（请求签名由页面自动附加，无需自行逆向）
3. **执行**：模拟点击「收藏 → 加入专辑 → 完成」，每条 10-15 秒
4. **安全**：不代登录、不存密码、不碰云端


## 运行环境（必读）

### ✅ 当前支持：电脑端

- **浏览器**：Chrome / Edge（已登录小红书网页版）
- **运行方式**：浏览器自动化 Agent（DSH / Playwright / 或手动配合脚本）
- 完整流程（盘点 → 清单 → 执行 → 复查）均可在电脑端完成

### ⏳ 手机端：测试中，暂未支持

目前**无法在手机上直接使用**，以下是探索中的三条通路（尚未打通，仅供参考）：

| 通路 | 思路 | 状态 |
|---|---|---|
| 手机浏览器 + 书签脚本 | 手机浏览器打开网页版，用 `javascript:` 书签调用页面接口 | 测试中（待验证手机网页版是否完整支持「加入专辑」）|
| 手机指挥电脑 | 手机访问电脑上的 DSH 界面，指令在电脑执行 | 局域网端口转发已跑通，认证配置待完善 |
| iOS 快捷指令 | 快捷指令直连 API | 不推荐（需逆向签名，不稳定）|

**结论：电脑当主力手；手机端只作为远期方向。** 如果你只有手机、没有电脑，目前用不了本工具。

## 使用方式（电脑端）

前提：已登录小红书网页版的 Chrome/Edge 浏览器 + 能执行浏览器自动化的 Agent（如 DSH、Playwright 或手动操作）。

步骤：
1. 打开收藏页 `https://www.xiaohongshu.com/user/profile/<你的uid>?tab=fav`
2. 执行盘点脚本（滚动抓取 + 专辑比对）
3. 审核分类清单，确认
4. 执行移动（UI 模拟点击，建议每批 50-100 条，间隔 10-15 秒）
5. 复查计数

| 内容 | 归入 |
|---|---|
| Codex / Obsidian / DSH / Mac 技巧 / PPT / 提示词 / Skill | AI 工具与效率 |
| Zotero / 论文 / 考研 / 书单 / 行业手册 | 学术与学习 |

| 本地探店 / 展览 / 周末日常 | 生活打卡与探店 |
| 樊振东 / 奥运 / 赛事 | 体育赛事 |
| 美食 / 餐厅 / 菜谱 | 美食收藏 |
| 美甲 / 发型 / 化妆 / 护肤 / 穿搭 | 对应专辑 |
| 五月天相关（任何元素） | 五月天 |
| 不确定 | 待归类（建议不超过总量两成）|

## 风控说明

- **滚动抓取**：等同浏览，零风险
- **UI 模拟点击**：接近真人操作，建议 10-15 秒/条、每小时不超过 80 条、每 20 条休息
- **API 批量写入**：能不用就不用（累计大量调用会触发平台限流）
- 遇到「异常访问」提示立即停手，冷却 24 小时
- 失效笔记（作者已删除）无法操作，会被跳过

## 使用建议

- 首次使用时先小批量（20-30 条）验证效果，再放大
- 建议分晚执行，每晚不超过 150 条
- 整理前先确认自己的专辑体系（增删改专辑会影响分类结果）
